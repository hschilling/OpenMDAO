# OpenMDAO Advanced Skills

These skills are for advanced OpenMDAO users tackling parallel execution, custom solvers, surrogate modeling, large-scale optimization, and performance profiling.

## Files
1. `01-parallel-execution.md` — MPI, distributed models, parallel drivers/groups
2. `02-custom-solvers.md` — Writing and integrating custom nonlinear/linear solvers
3. `03-surrogate-models.md` — Using MetaModelUnStructuredComp and surrogates
4. `04-large-scale-optimization.md` — Scaling up, memory, decomposition, iterative solvers
5. `05-performance-profiling.md` — Profiling, timing, optimizing model speed

## Usage
Load these files into your Claude Project or Claude Code workspace for advanced guidance.
