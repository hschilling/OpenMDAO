# OpenMDAO Patterns and Recipes Skills

These skills provide practical, annotated recipes for common OpenMDAO patterns and problems.

## Files
1. `01-sellar-problem.md` — Classic Sellar problem, fully annotated
2. `02-paraboloid-optimization.md` — Paraboloid optimization recipe
3. `03-multidisciplinary-coupling.md` — MDA/MDO coupling pattern
4. `04-external-code-wrapping.md` — Wrapping external codes (Fortran, C, MATLAB)

## Usage
Load these files into your Claude Project or Claude Code workspace for practical, ready-to-use patterns.
