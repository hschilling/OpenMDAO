# OpenMDAO Beginner Skills

These skills help Claude guide new users through learning OpenMDAO. They are organized in a tutorial sequence — each builds on the previous.

## Files
1. `01-mental-model.md` — Core concepts and the dataflow graph metaphor
2. `02-first-component.md` — Building an ExplicitComponent (Paraboloid)
3. `03-variables-and-units.md` — Variable declaration, units, set_val/get_val
4. `04-connecting-components.md` — connect() vs promotes, avoiding silent collisions
5. `05-groups-and-hierarchy.md` — Groups, hierarchy, variable paths
6. `06-running-your-model.md` — Execution lifecycle
7. `07-first-optimization.md` — Drivers, design variables, objectives, constraints
8. `08-understanding-convergence.md` — Coupling, solvers, convergence debugging
9. `09-debugging-basics.md` — N2, list_connections, check_partials

## Stumbling Blocks Addressed
- Mental model: files 01, 03
- Connections: files 04, 05
- Convergence: files 08, 09

## Usage
Load these files into your Claude Project knowledge base, or include them in your Claude Code workspace at `.claude/skills/openmdao-beginner-skills/`.
